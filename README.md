# Clavier Chrono — séance TICE 6e

Mini-site autonome pour une séance de 55 minutes. Il fonctionne hors ligne, sans bibliothèque externe, compte élève ni donnée personnelle.

## Tester sur son ordinateur

Ouvrir `index.html` dans un navigateur récent. Les fichiers `index.html`, `style.css` et `script.js` doivent rester dans le même dossier.

## Mettre en ligne avec GitHub Pages

1. Créer un dépôt GitHub.
2. Déposer `index.html`, `style.css` et `script.js` à la racine du dépôt.
3. Dans **Settings → Pages**, choisir **Deploy from a branch**.
4. Sélectionner la branche `main`, le dossier `/ (root)`, puis enregistrer.
5. Après quelques minutes, ouvrir l’adresse indiquée par GitHub Pages.

## Déroulé conseillé (55 min)

- 5 min : accueil et consigne ;
- 8 min : défi 1, repérer les touches importantes ;
- 12 min : défi 2, reproduire exactement trois chaînes ;
- 10 min : défi 3, corriger avec Retour arrière et Suppr ;
- 6 min : défi 4, utiliser Maj et Alt Gr ;
- 6 min : défi 5, choisir les raccourcis essentiels ;
- 5 min : bonus chronométré ;
- 3 min : bilan et rangement.

Le score maximal est de **5 600 points** : 1 000 points par défi obligatoire et jusqu’à 600 points de bonus. Les aides ne retirent aucun point. Le bonus est facultatif et ne peut pas diminuer le score.

## Notes pédagogiques

- La saisie exacte est comparée caractère par caractère, espaces et casse compris.
- Le clavier dessiné représente un AZERTY scolaire simplifié ; certaines machines peuvent avoir une disposition légèrement différente.
- Le site rappelle que **Maj** agit pendant qu’on la maintient, tandis que **Verr. Maj** reste actif jusqu’au prochain appui.
- Aucun résultat n’est envoyé sur Internet. Le bouton d’impression permet de conserver le bilan final.

## Barème et bilan

- Chaque bonne action rapporte les points prévus pour le défi.
- Une erreur retire de 20 à 50 points selon le type d’exercice.
- Le malus est plafonné à 500 points par défi afin de rester encourageant.
- Une erreur dans le bonus réduit seulement les points du bonus : elle ne touche jamais le score principal.
- Consulter un coup de pouce ne retire aucun point.

Le bilan distingue le score principal sur 5 000 points du bonus sur 600 points. Il affiche pour chaque défi le score, le pourcentage, le nombre d’erreurs et le niveau atteint : **Maîtrisé**, **À consolider** ou **À retravailler**.
